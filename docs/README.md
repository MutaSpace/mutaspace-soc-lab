# MutaSpace SOC Lab Documentation

This folder contains the main documentation for the MutaSpace SOC Lab.

The purpose of this documentation is to make the lab understandable, reproducible, and useful for different audiences, including beginners, students, educators, cybersecurity professionals, and anyone learning how to build a hands-on SOC environment.

## What This Folder Will Include

As the lab grows, this folder will include documentation for:

- Custom PC hardware build
- Proxmox installation and validation
- Proxmox storage configuration
- Proxmox network design
- Virtual machine planning
- Firewall/router setup
- Wazuh SIEM deployment
- Suricata network monitoring
- Windows endpoint telemetry
- Linux endpoint telemetry
- Detection engineering
- Learner scenarios
- Troubleshooting notes
- Validation checklists

## Documentation Standard

Each major document should explain:

1. What is being built or configured.
2. Why it matters.
3. What tools or systems are involved.
4. What steps were taken.
5. How the step was validated.
6. What problems or lessons were discovered.

The goal is not only to show that the lab works.

The goal is to make the lab understandable enough that someone else could learn from it and eventually recreate their own version.
